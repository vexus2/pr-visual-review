# 画像上の注釈

- [x] 既存の並列表示に、番号・通常変更・問題の区別を追加。Beforeは参照枠。
- [x] case.annotationsへ原画像に対する正規化矩形と説明を記録。範囲外、重複番号、未撮影、対応するissueなしを拒否。
- [x] HTMLはCSS overlayと原画像へのリンク、凡例を表示。原画像ファイルは変更しない。
- [x] 任意のPillow依存で静的PNGを出力。JSONも別名へ保存。出力のfingerprintを照合して、古い注釈の公開を防ぐ。
- [x] Markdown/PRは静的PNGと原画像リンクを表示。必要なPNGやURLがない場合は投稿を止める。
- [x] デモの既存画像を目視して注釈を付ける。画面外の保存ボタン自体を画像内へ描き足さない。
- [x] 自動テスト、独立したSkill適用評価、実ブラウザでの表示確認を実施。

Python標準ライブラリだけのHTML/通常レポートを維持します。PNGの書出しだけPillowが必要です。英語・日本語READMEとSkillを更新します。
