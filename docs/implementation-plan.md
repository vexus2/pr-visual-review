# PR Visual Review 初版実装計画

**目的:** 添付された全体設計を、Codex / Claude Code が実行できる配布用 Skill として実装します。
**設計:** AI が対象選定・起動・実ブラウザ操作・画像確認を担い、Python 標準ライブラリの補助コードが記録検証・Markdown 作成・GitHub コメント更新を担います。Playwright テスト、画像ホスティングサービス、任意アプリの自動起動 CLI は作りません。
**設計元:** ユーザー提供の対話「PRを渡すと、AIが変更箇所を実際の画面で確認し、Before／Afterと所見をPRに残すスキル」。その設計での実装依頼を受けて進めます。

- [x] 対話と既存ファイルを確認。作業フォルダは空で Git 未初期化。
- [x] Skillなしの独立シナリオ評価。6ケース中、新規画面で404画像を通常のBeforeとして示す提案がありました。初版では「存在しない」の明記を必須とし、404は比較画像として代用しません。他5ケースでは明確な逸脱は観測されませんでした。
- [x] `tests/test_review.py`: ローカル画像、存在しない画面、未確認、危険なURL、投稿の許可条件、他人のコメント、ページング、head変更、更新と作成のテストを先に実行します。
- [x] `pr-visual-review/SKILL.md` と `references/`: 共通手順、コミット固定、同一状態、Codex / Claude接続、認証、画像掲載、終了処理を記述します。
- [x] `pr-visual-review/scripts/review.py`: `render` と既定dry-runの `publish` を実装します。起動やブラウザ操作をこのスクリプトに隠しません。
- [x] `templates/report.json`, `examples/`, `README.md`, `agents/openai.yaml`: 保存形式、説明用サンプル、導入手順を用意します。実PRでの成功例とは表示しません。
- [x] 単体テスト、ローカルGit/HTTPの簡易実行、スキル構造検証、Skillありの独立シナリオ評価を行います。

検証上の重点: 間違ったコミット、未確認を差分なし扱い、同名markerだけで他人のコメントを更新、headが撮影後に変化、ローカル画像パスのGitHub投稿。
今回の実PR指定はないため実PRへの書き込みはしません。公開、push、ライセンス名義の決定は実装に含めません。
