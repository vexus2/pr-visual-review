# PR Visual Review 改善計画

目的: 実行例で観測した判定・比較の課題を修正し、PCのみ / SPのみ / 両方を指定できるようにします。

- [x] report v2: scope（対象端末）、caseごとのdevice/viewport、alignment（撮影基準）、issues（由来と対応判断）を追加します。v1は読み取り互換を保ち、未記録の分類を推測しません。
- [x] 範囲: 明示された端末と幅を尊重します。指定なしはPC 1280x1000、SP指定のみは390x844。両方はそれぞれ1幅。リポジトリの既定サイズがあれば優先。幅の追加や実機扱いを勝手に行いません。
- [x] 判定: 今回発生 / 今回悪化 / 既存 / 因果未確定と、PRで要対応 / 任意改善 / 要調査を分離します。既存問題や折返しだけをPR必須修正へ昇格しません。
- [x] 比較: 共通要素による位置合わせとcontext画像を基本に、必要な詳細画像を追加。数値scrollYだけの一致を比較可能の証明にしません。
- [x] HTML: 同じJSONからMarkdownとオフラインHTMLを標準生成。スクリプトや外部assetsなし。既存レポートの白背景・青系・2列比較を引き継ぎ、要点と詳細を分離します。
- [x] 検証: 失敗テスト→実装→既存テストを含めて確認。独立シナリオ評価。既存実行例を別ファイルで再表示し、旧ファイルは保持。新しい撮影は行わず撮影日/SHAを保持します。

対象: SKILL.md, scripts/review.py, assets/report.css, references, templates/report.json, README.md, tests/test_review.py。
今回GitHub投稿、対象プロジェクトのコード変更、既存PRの再撮影は含めません。
